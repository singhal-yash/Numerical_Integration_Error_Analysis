RESULTS DIRECTORY (`results/`)

Purpose:
This directory stores the numerical results generated by the project's experiments.

Planned outputs:
1. Error comparison tables.
2. Convergence analysis results.
3. Plots comparing errors for both integration methods.
4. Results for different test functions and subdivision counts.

Each result should clearly identify:
- Test function and exact integral.
- Integration interval.
- Number of subdivisions (n).
- Numerical approximation.
- Absolute error.
- Observed convergence order, where applicable.

Use descriptive filenames and ensure results can be reproduced using the project's code.
