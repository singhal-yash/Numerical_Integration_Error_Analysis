# Numerical_Integration_Error_Analysis


## Objective

Implement composite numerical integration methods and investigate how their accuracy depends on the integrand and the number of subintervals. Implement the composite trapezoidal rule and composite Simpson's 1/3 rule, compare their performance on functions with known integrals, and use the experiments to examine error and convergence.
