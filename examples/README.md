EXAMPLES DIRECTORY (`examples/`)

Purpose:
This directory contains simple, runnable examples demonstrating how to use the numerical integration functions.

Planned examples:
1. Integrate a smooth function with a known exact integral.
2. Compare the Trapezoidal Rule and Simpson's 1/3 Rule.
3. Demonstrate how changing the number of subdivisions affects accuracy.

Each example should:
- Import functions from the src directory.
- Specify the function, integration interval, and subdivision count.
- Display the numerical approximation and relevant comparison values.
- Include comments explaining the experiment.

Keep examples short, reproducible, and easy to understand.
