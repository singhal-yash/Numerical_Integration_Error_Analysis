REPORT DIRECTORY (`report/`)

Purpose:
This directory contains the final report for Scientific Computing Project 7 - Numerical Integration and Error Analysis.

Planned report sections:
1. Introduction and project objectives.
2. Mathematical formulation of both numerical integration methods.
3. Implementation details and input validation.
4. Experimental setup and test functions.
5. Numerical results, error tables, and plots.
6. Observed convergence orders and comparison with theoretical expectations.
7. Interpretation of results and conclusions.

The report should explain the accuracy and convergence behavior of both methods and discuss any assumptions or limitations.

Include only verified results generated by the project's implementation.
