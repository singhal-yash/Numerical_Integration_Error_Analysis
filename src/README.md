SOURCE CODE DIRECTORY (`src/`)

Purpose:
This directory contains the main Python implementation of the numerical integration project.

Planned files:
1. trapezoidal.py — Composite Trapezoidal Rule implementation (Member 1).
2. simpson.py — Composite Simpson's 1/3 Rule implementation (Member 2).
3. error_analysis.py — Absolute error and convergence order calculations (Member 3).
4. experiments.py — Experiment execution and result collection (Member 4).

Guidelines:
- Keep each algorithm in its own Python file.
- Use descriptive function and variable names.
- Add docstrings, input validation, and meaningful error messages.
- Avoid duplicating functionality across modules.
- Import functions from their respective modules when needed.
